# Skill: Storyboard

Übersetzt ein Brief in Shots. Reihenfolge: Beat-Liste → Shot-Liste → Prompts (dann Prompt-Baukasten).

## 1. Beat-Liste (Dramaturgie)

Brief in Beats zerlegen. Faustregeln nach Länge:

- **15–30s (Ad/Short):** 3–5 Beats — Hook (0–3s) → Spannung → Wendepunkt → Payoff.
- **60–90s:** 6–8 Beats, alle 10–15s ein Beat-Wechsel.
- Hook-Regel: die ersten 3 Sekunden zeigen das Interessanteste, nicht das Logo.

## 2. Shot-Liste (dramaturgisch → filmisch)

Pro Beat 1–3 Shots. Für jeden Shot festhalten:

| # | Beat | Shot-Typ | Inhalt | Dauer | Übergang |
|---|---|---|---|---|---|
| 1 | Hook | Extreme Close-up | … | 2s | hart |

Shot-Typen sinnvoll mischen: Weit (Kontext) → Mittel (Aktion) → Nah (Emotion). Nicht 5 Nah-Shots hintereinander.

## 3. Kontinuitäts-Header (vor den Shots ins Projekt eintragen)

```markdown
**Figur:** [feste Merkmale, die in JEDEN Prompt übernommen werden]
**Ort/Licht:** [ebenso]
**Stil:** [Filmreferenz]
```

## 4. Output

Shot-Liste in `projekte/projekt_NN.md` ergänzen, dann pro Shot den Prompt aus dem Baukasten darunter schreiben. Fertig = jede Zeile der Shot-Liste hat einen Prompt + eine Variante.
